# 分科六法庫

本 Skill 只負責指路。規則、指令和設定檔格式，全部寫在本庫 `tools/` 資料夾：

- 指引：`tools/使用指引.md`
- 主程式：`tools/法規庫.py`；登錄表 `tools/法規登錄.json`；各法設定 `tools/設定/<法規全名>.json`；來源檔放 `tools/來源/`

路徑都相對於本庫根目錄（含有 `分科六法整理/` 與 `tools/` 的資料夾）。如果 Claude Code 不是在本庫根目錄啟動，先問使用者本庫的位置。

## 開工

1. 用 Read 讀完 `tools/使用指引.md` 全文才動手（摘要不算）。
2. 第一次執行前確認 Python 套件已安裝：`python -m pip install -r tools/requirements.txt`。
3. dry-run 的輸出資料夾一律放在本庫之外（指引用 `../../試跑暫存`），不要寫進本庫。
4. 依指引第四節的五個步驟進行：登錄 → scan → 補設定檔並跑 check-ext → dry-run → build → 回報。
5. 修法更新走第五節。

## 不可違反

- 條文只能來自全國法規資料庫：來源檔，或 `mcp-taiwan-legal-db`／官方網頁。外部條文一定要過 `check-ext`。
- 自擬條名只填名稱，由腳本加「〔自擬〕」，不得寫進 `caption`。
- 不刪頁、不整頁重建、不改條文區以外的內容。要改版型就改 `法規庫.py` 後重跑。
- 在 `tools/` 資料夾內用 `python -I` 執行；寫檔後以輸出的「輸出位置」確認位置與檔數。
- 分類或簡稱不明、外部法規的條號範圍、效力狀態有疑義時，回報使用者，不要自行推定。
